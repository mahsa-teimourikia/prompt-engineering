# Curated resource library

## Primary papers

- [The Prompt Report](https://arxiv.org/abs/2406.06608) — broad technique taxonomy.
- [Systematic survey of prompt engineering](https://arxiv.org/abs/2402.07927) — applications and technique overview.
- [Chain-of-Thought](https://arxiv.org/abs/2201.11903), [Self-Consistency](https://arxiv.org/abs/2203.11171), [Tree of Thoughts](https://arxiv.org/abs/2305.10601), [ReAct](https://arxiv.org/abs/2210.03629), [Toolformer](https://arxiv.org/abs/2302.04761), and [DSPy](https://arxiv.org/abs/2310.03714).

## Official guidance

- [OpenAI prompting](https://platform.openai.com/docs/guides/prompting), [structured outputs](https://platform.openai.com/docs/guides/structured-outputs), [function calling](https://platform.openai.com/docs/guides/function-calling), [evals](https://platform.openai.com/docs/guides/evals).
- [Anthropic context engineering](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents) and [effective agents](https://www.anthropic.com/engineering/building-effective-agents).
- [Google prompt design](https://ai.google.dev/gemini-api/docs/prompting-strategies), [structured output](https://ai.google.dev/gemini-api/docs/structured-output), and [function calling](https://ai.google.dev/gemini-api/docs/function-calling).

## Tools and evaluation ecosystems

- [Pydantic](https://docs.pydantic.dev/) for Python validation.
- [DSPy](https://dspy.ai/), [Promptfoo](https://www.promptfoo.dev/), [LangSmith](https://docs.smith.langchain.com/), and [Arize Phoenix](https://docs.arize.com/phoenix) for optimization, testing, tracing, and evaluation.

## Security and governance

- [OWASP AI Agent Security](https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html)
- [OWASP Secure AI Model Ops](https://cheatsheetseries.owasp.org/cheatsheets/Secure_AI_Model_Ops_Cheat_Sheet.html)
