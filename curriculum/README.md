# Prompt Engineering Curriculum

The curriculum progresses from prompt structure to production AI system
engineering. Courses are numbered in learning order and grouped into four
levels.

| Level | Course range | Track |
|---|---:|---|
| [Beginner](beginner/README.md) | 01–05 | Prompt payloads, contracts, examples, typed outputs, and technique selection |
| [Intermediate](intermediate/README.md) | 06–13 | Reasoning, workflows, context, conversations, retrieval, tools, multimodality, and security |
| [Advanced](advanced/README.md) | 14–21 | Evaluation, judges, optimization, agents, coding, model awareness, and efficiency |
| [Enterprise](enterprise/README.md) | 22–29 | PromptOps, observability, release engineering, governance, trust, portability, architecture, and the capstone |

## Learning order

Start with [Beginner](beginner/README.md), continue through
[Intermediate](intermediate/README.md), then complete
[Advanced](advanced/README.md) and [Enterprise](enterprise/README.md).
Every numbered course contains a README, one course notebook, and a diagram.
The course 29 README also links its five milestone notebooks.
