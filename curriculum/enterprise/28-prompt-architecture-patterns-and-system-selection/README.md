# 28 — Prompt Architecture Patterns and System Selection

## Learning objectives

Choose among deterministic software, single prompts, typed outputs,
multi-stage workflows, RAG, tool-using workflows, agents, and multi-agent
systems using reliability, cost, latency, security, observability, and
evaluation requirements.

## Lab and production

The [notebook](prompt_architecture_patterns_and_system_selection.ipynb) selects
the least complex architecture for deterministic, evidence, and action
requirements. [lab.py](lab.py) makes the selection rule inspectable. In a real
architecture decision record, compare at least 12 scenarios and justify why
simpler and more complex alternatives do not fit.
